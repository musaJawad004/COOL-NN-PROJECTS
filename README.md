# COOL Neural Network Projects

A collection of visual, educational AI experiments built with Python, PyTorch,
and Tkinter.

## Projects

| Project | Technique | What it demonstrates |
|---|---|---|
| Genetic Text Evolver | Genetic algorithm | Selection, crossover, mutation, and live fitness |
| Neural Maze Brain | Deep Q-Network | Reinforcement learning, replay memory, and policy visualization |
| Neural Car Driving Simulator | Neuroevolution | Sensor-driven neural controllers and evolving populations |
| Neural Voice Emotion Detector | Convolutional neural network | Log-mel audio features and emotion classification |

Each project is self-contained inside `projects/` and includes its own README,
launcher, requirements, and tests.

## General requirements

- Python 3.11 or newer
- macOS, Linux, or Windows with Tk support
- PyTorch for neural-network projects

Open an individual project directory and follow its README to run it.

## Disclaimer

These applications are educational demonstrations. The emotion detector is not
a medical or psychological assessment, and synthetic demo audio does not
represent genuine human emotional speech.
